# Cristian Espiritu — Portfolio

Open `index.html` in a browser.

## Included
- Responsive portfolio layout
- About, skills, experience, education, and contact sections
- Mobile navigation
- Scroll reveal animations
- Profile image cropped from the provided CV
- No framework required

## Easy customization
Replace or edit the content in `index.html`.
Edit colors, spacing, and typography in `style.css`.
Edit interactions in `script.js`.

## Portfolio additions
The copy is polished from the supplied CV. Any new portfolio/project claims should be replaced with your real projects, GitHub, LinkedIn, and Upwork links before publishing.
